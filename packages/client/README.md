# @frappeforge/client

Zero-dependency, `fetch`-native TypeScript client for the Frappe Framework REST API.

> **Status:** pre-release scaffold. The public API is under construction; nothing here is
> stable yet. Watch the [repository](https://github.com/frappeforge/frappeforge) for progress.

## Install

```sh
pnpm add @frappeforge/client
```
